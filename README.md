# مشلكة توزيع المهام

## وصف المشروع
يهدف هذا المشروع إلى حل مشكلة توزيع المهام على الموظفين مع تقليل أطول وقت يحتاجه موظف لإنهاء جميع مهامه، وذلك باستخدام ثلاث خوارزميات:
1. الخوارزمية الجينية Genetic Algorithm - GA
2. خوارزمية الأسراب Particle Swarm Optimization - PSO
3. خوازرمية مستعمرة النمل Ant Colony Optimization - ACO
## المتطلبات
يجب أن تكون لغة python3 مثبتة على جهازك، بالإضافة إلى مكتبة matplotlib من أجل رسم المخططات البيانية. من أجل تثبيت المكتبة، افتح الـterminal واكتب:
```Bash
pip install matplotlib
```
## الملفات
- ``main.py``: الملف الرئيسي الذي يقوم بتشغيل الخوارزميات الثلاثة ومقارنتها
- ``genetic_algorithm.py``: الملف الخاص بالخوارزمية الجينية
- ``swam_algorithm.py``: الملف الخاص بخوارزمية الأسراب
- ``ant_colony_algorithm.py``: الملف الخاص بخوارزمية مستعمرة النمل
- ``generate_test.py``: الملف المسؤول عن توليد اختبارات عشوائية بأحجام مختلفة، ولا حاجة لاستخدامه إلا عند الرغبة بتغيير البيانات ضمن ملفات الاختبار الجاهزة
- ``{size}_test{number}.txt``: ملفات اختبار جاهزة من أجل تجربة الخوارزميات
## كيف يتم تشغيل المشروع
- في حال أردت مقارنة الخوارزميات الثلاثة:

    ```Bash
    python3 main.py
    ```
    سيطلب منك البرنامج إدخال:
    1. حجم ملف الاختبار (s للصغير, m للمتوسط, l للكبير)
    2. رقم ملف الاختبار: إما 1 أو 2 أو 3
    3. عدد مرات التشغيل (مثلا 5)

    المخرجات: 
    - طباعة النتائج (المدة الزمنية التي استهلكتها كل خوارزمية، الذاكرة، المدة أثناء حساب الذاكرة، أفضل قيمة ملاءمة) على الـ terminal
    - إنشاء ملف ``results.txt`` يحتوي على هذه النتائج
    - ملفات ``{algorithm_name}_solution_for_{test_file_name}.txt`` تحتوي على توزيع المهام الأفضل من أجل كل خوارزمية
    - عرض مخطط بياني يقارن سرعة التقارب وقيم الملاءمة للخوارزميات الثلاثة

- في حال أردت تشغيل خوارزمية واحدة:

    يمكنك تشغيل أي خوارزمية بشكل مستقل، مثلا:
    ```Bash
    python3 genetic_algorithm.py
    ```
    
    المخرجات: 
    - طباعة النتائج (المدة الزمنية التي استهلكتها الخوارزمية، الذاكرة، المدة أثناء حساب الذاكرة، أفضل قيمة ملاءمة) على الـ terminal
    - ملفات ``{algorithm_name}_solution_for_{file_name}.txt`` تحتوي على توزيع المهام الأفضل من أجل كل خوارزمية
    - عرض مخطط بياني يقارن سرعة التقارب وقيم الملاءمة للخوارزمية 




## ملاحظات
- تم تقسيم عمليتي مراقبة مدة تنفيذ الخوارزمية ومراقبة استهلاك الذاكرة بسبب أن مراقبة الذاكرة تضاعف زمن التنفيذ بين الضعف والثلاثة أضعاف (ما عدا خوارزمية الأسراب التي تأخذ من 6 إلى 7 أضعاف زمن التنفيذ) بسبب طريقة عمل ``tracemalloc``. لذلك، ومن أجل عدم تأثر حسابات مدة التنفيذ بهذا التأخر، تم فصل العمليتين عن بعضهما.
- يتم حساب أكبر استهلاك للذاكرة مرة واحدة فقط ضمن التشغيل الواحد، حتى لو كان عدد التكرارات للخوارزمية runs، أكبر من واحد، وذلك للأسباب التالية:
    - استهلاك الذاكرة لكل خوارزمية لا يختلف كثيرا بين التكرارات، حيث لا يتعدى 1 كيلوبايت
    - الوقت الذي يستهلكه حساب استهلاك الذاكرة من أجل الاختبارات الكبيرة كبير جداً مقارنة بوقت التنفيذ الفعلي
